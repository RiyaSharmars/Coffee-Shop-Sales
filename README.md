# ☕ Coffee Shop Sales Dashboard (Excel Project)

This project showcases an interactive **Excel dashboard** for analyzing sales data of a coffee shop chain. Built using pivot tables, charts, and slicers, the dashboard provides deep insights into sales trends, customer behavior, product performance, and store-level performance.

---

## 📌 Project Summary

- **Title:** Coffee Shop Sales Dashboard
- **Tool Used:** Microsoft Excel
- **Domain:** Retail / Food & Beverage
- **Type:** Interactive Excel Dashboard
- **Data Source:** Raw sales and store performance data

---

## 🎯 Project Objectives

- Identify top-selling products and categories
- Analyze hourly and weekday-based customer behavior
- Track store-wise sales and customer footfall
- Understand order size and product preferences

---

## 📊 Key Metrics

- 💰 **Total Sales:** ₹6,98,812.33  
- 🚶 **Total Footfall:** 149,116  
- 📄 **Avg. Bill / Person:** ₹4.69  
- 🍽️ **Avg. Orders / Person:** 1.44  

---

## 🧩 Dashboard Features

- 📅 **Time Filters:** Month and Day slicers for easy filtering
- ⏰ **Quantity by Hour:** Shows peak order hours
- 🥇 **Top 5 Products:** Based on total sales (e.g., Barista Espresso, Chai Tea)
- 🧃 **Order Size Distribution:** Regular and Large dominate
- 📦 **Category-wise Sales %:** Coffee and Branded items lead
- 📍 **Store-wise Sales & Footfall:** Hell’s Kitchen, Lower Manhattan, and Astoria stores analyzed
- 📈 **Orders by Weekday:** Friday has the highest number of orders
